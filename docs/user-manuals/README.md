# Equiwings CMS — User Manuals

A separate, plain-language quick-start guide for every role in the system. Hand each
person **only the file for their role** — each one is self-contained and explains exactly
what that user sees, what they can do, and how to do the most common tasks.

> **Tip:** these are Markdown files. To share as PDF or Word, open one in any Markdown
> viewer (or VS Code → "Markdown: Open Preview" → print to PDF), or paste into Google Docs.

## A note on what each person sees
The menu and screens are tailored to the role **and** to the modules your club has switched
on. If a guide mentions something marked *"(if your club has this turned on)"* and the user
doesn't see it, that feature simply isn't enabled for your club — that's expected, not a bug.

## Two roles intentionally have no manual
The system currently has a few accounts tagged **`JURY`** and **`COMPETITION_MANAGER`**.
These are **not roles the application supports** — they don't map to any menu or permissions,
so a user with one of them would log in to an almost-empty screen and be unable to do anything.
There's no manual for them because there are no features to document. If those people need
access, ask your administrator to switch their accounts to a supported role from the table above.
